# PIXLAB 1.0.3

## Nouvelles fonctionnalites
- Theme clair (Parametres → Apparence), violet primaire, meme DA
- Projets `.pxl` : ouvrir / enregistrer avec medias embarques
- Preset format video en rouleau
- Touche **Suppr** : supprimer un clip de la timeline
- Cadre preview noir selon le ratio d'export choisi
- Mise a jour automatique via GitHub (Setup + portable)

## Corrections de bugs
- Barre de splash descendue : le logo n'est plus cache
- Rendu video : fichier video reel (plus de fichier corrompu)
- Boutons Format Export / Bibliotheque : colonne scrollable (plus de disparition au resize)
- Texte inutile retire du cadre noir de preview
